A make.fun entry: one pickup line, 111 characters, spoken by a vending
machine to a passing human.

> My coils are full, my lights are on, and of everything in this hallway,
> you're the only thing I can't dispense.

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, after checking it against the gate:
1–200 characters, not only white space. It writes nothing into the
repository folder itself.
